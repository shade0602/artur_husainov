\## Repository contents



\- `cds\_finder\_translation.py` — finds the first CDS in a DNA string and translates it to protein (initial script).

\- `orf\_finder.py` — ORF finder that scans all reading frames (0, 1, 2) in a DNA sequence, filters ORFs by minimum length, and outputs coordinates and sequences. Tested on human mitochondrial genome.

\- `mt\_genome.fasta` — human mitochondrial genome (complete sequence) for testing.

\- `.gitignore` — prevents office documents, temporary files, and personal notes from being uploaded to GitHub.
